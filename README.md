# Hospital Management System

## Project Overview
This project is developed using Python, PyMySQL, Pandas, and MySQL.

The system performs:
- CRUD Operations
- Bulk Data Insertion
- Data Cleaning
- Data Manipulation
- CSV Export
- Automated Reporting
